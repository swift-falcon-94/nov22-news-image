The World Today — 22 November 2026: 42 stories, 7 regions. One dense 1024x1024 image summing up the world's news of Sunday 22 November 2026: COP31 collapses in Antalya with no deal, the Cikande factory-fire search, a Russian drone flattens a flat in Dymer, plus a world map with 13 pinned stories, a day-in-numbers strip, a region bar, certainty tags on every story, a date-check box, and 29 more stories across every region.

## Run it

```sh
python3 main.py
```

Writes `entry.png` to `/output` (or `$MAKEFUN_OUTPUT_DIR` when set). Pure Python standard library, deterministic, no network: renders at 2048x2048 with 2x supersampling and true device-space rasterisation, then averages down to 1024x1024.
